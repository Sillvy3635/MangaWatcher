# แหล่งข้อมูล metadata ที่ตรวจสอบแล้ว

ตรวจเอกสารทางการและทดสอบการตอบกลับแบบอ่านอย่างเดียวถึง 20 พฤศจิกายน 2026 รายการนี้เป็นแหล่ง **metadata** ไม่ใช่สิทธิ์ดาวน์โหลดภาพตอนหรือเข้าถึงตอนที่ต้องชำระเงิน เงื่อนไขของแต่ละบริการอาจเปลี่ยนได้

| แหล่ง | หลักฐานช่องทางที่เผยแพร่ | ใช้กับ MangaWatcher | ข้อจำกัด |
| --- | --- | --- | --- |
| [MangaDex](https://gitlab.com/mangadex-pub/mangadex-api-docs/-/blob/main/index.md) | เอกสารระบุว่า API สาธารณะและใช้ฟรีสำหรับโครงการที่ทำตาม Acceptable Usage Policy; ทดลอง `GET /manga?limit=1` ได้ HTTP 200 | มี `mangadex` adapter และเปิดตรวจ ENG 2 แหล่งที่ยืนยันชื่อเกาหลี/เรื่องย่อตรงแล้วใน private data; Workflow ตรวจจริงสำเร็จ | ต้องให้เครดิต MangaDex, ไม่มีโฆษณาหรือบริการเก็บเงิน, เคารพ [rate limit](https://gitlab.com/mangadex-pub/mangadex-api-docs/-/blob/main/rate-limits.md); การมีตอน RAW/ENG/TH ขึ้นอยู่กับที่มีจริงใน MangaDex และต้องยืนยันการจับคู่เรื่อง |
| [Thunder Scans RSS](https://en-thunderscans.com/feed/) | เว็บเผยแพร่ RSS ตอนพร้อม URL และวัน; ทดลอง 6 หน้าฟีดได้ HTTP 200, Worker production อ่านได้จริง | เปิด `site_feed` ให้ 12 เรื่องเดิม กรอง URL ตอนและชื่อเรื่องตรงกับ URL หน้าเรื่อง ตรวจทุก 60 นาที | [ข้อกำหนด](https://en-thunderscans.com/terms-and-conditions/) ห้าม spider/crawl/scrape จึงใช้เฉพาะ RSS ที่เว็บเผยแพร่เอง ไม่อ่าน HTML อัตโนมัติ; 6 หน้าฟีดเป็นช่วงจำกัด ทุกเรื่องยังไม่ปรากฏในช่วงล่าสุด จึงยังยืนยันเลขตอนสดไม่ได้ |
| [QiManga RSS](https://qimanga.com/rss.xml) | เว็บเผยแพร่ RSS ตอน 100 รายการพร้อม URL และวัน; ทดลอง HTTP 200, Worker production อ่านได้จริง | เปิด `site_feed` ให้ 1 เรื่องเดิม กรอง URL รายเรื่องและชื่อเรื่องตรงตัว ตรวจทุก 60 นาที | [ข้อกำหนด](https://qimanga.com/terms-of-service) จำกัดการใช้ระบบอัตโนมัติและห้ามข้ามระบบป้องกัน; ใช้ RSS หนึ่งคำขอต่อรอบ ไม่อ่านตอน Premium; เรื่องที่ติดตามยังไม่อยู่ในฟีดล่าสุด จึงยังยืนยันเลขตอนสดไม่ได้ |
| [MangaUpdates](https://mangaupdates.apidocumentation.com/) | API ทางการเปิด public functions โดยไม่ต้องมีบัญชี และมี Acceptable Use Policy; `GET /series/{id}/rss` ทดลองได้ HTTP 200 | มีข้อมูล release ต่อเรื่อง แต่ RSS ที่ทดลองมีชื่อบทโดยไม่มี URL ตอน, GUID หรือวันเผยแพร่ จึงต้องทำ adapter เฉพาะก่อนใช้ | ให้เครดิต, เว้นช่วงคำขอและ cache; ข้อมูล release เป็นรายการที่ชุมชนบันทึก ไม่ใช่หลักฐานการเผยแพร่บนเว็บต้นทางหรือภาษา RAW/ENG/TH ที่ยืนยันแล้ว |
| [WEBTOON ภาษาอังกฤษ](https://www.webtoons.com/en/tiptoon/webtoon-now/list?title_no=2025) | หน้ารายเรื่องมีลิงก์ RSS ทางการ; ทดลอง feed ได้ HTTP 200 และมี item URL/วันเผยแพร่ | เป็นตัวเลือกสำหรับเรื่องบน WEBTOON EN แต่ parser ปัจจุบันยังไม่อ่านเลขตอนแบบ `Ep.`/`Episode` ครบ ต้องปรับ adapter และทดสอบก่อนเปิด | ใช้เฉพาะข้อมูลใน feed สาธารณะ ไม่เข้าตอนในแอปหรือผ่าน paywall; [ข้อกำหนด](https://www.webtoons.com/en/terms) ห้ามการรวบรวมข้อมูลอัตโนมัติที่ไม่ได้รับอนุญาต การมีลิงก์ RSS เป็นช่องทางที่เว็บเผยแพร่เอง แต่ไม่ได้ยืนยันสิทธิ์นำข้อมูลไปเผยแพร่ซ้ำในบริการอื่น |
| [MangaBaka](https://mangabaka.org/developers) | API ทางการเปิด public endpoints โดยไม่ต้องมีบัญชี; ทดลอง `GET /v2/series/1995?schema=full` ได้ HTTP 200 | เหมาะกับค้นหาเรื่อง, ชื่อภาษาอื่น, alias และลิงก์อ้างอิง โดยต้องให้ผู้ใช้ยืนยันการจับคู่; ยังไม่มี adapter | [ข้อกำหนดข้อมูล](https://mangabaka.org/about/data-license) อนุญาต MangaBaka Data สำหรับงานส่วนตัว/ไม่แสวงกำไรโดยให้เครดิตและทำตาม CC BY-NC-SA 4.0 แต่ข้อมูลจากผู้ให้บริการอื่นใต้ `source` มีข้อจำกัดแยก; [ข้อมูลเรื่องรีเฟรชทุก 1–7 วัน](https://mangabaka.org/developers/concepts/data-and-sources) และ API ปัจจุบันไม่มี feed ตอนใหม่รายเว็บ/ภาษา จึงไม่ใช้แทนการตรวจ RAW/ENG/TH หรือ Asura |

สำหรับ [Asura Scans](https://asurascans.com/terms-of-service) ข้อกำหนดระบุว่าห้าม scrape/copy โดยไม่ได้รับอนุญาต, `/feed` และ `/rss.xml` ตอบ 404 และคำขออัตโนมัติหน้าเว็บที่ทดสอบก่อนหน้านี้ได้ HTTP 403 จึงไม่เปิด HTML adapter หรือข้ามการป้องกัน ต้องได้รับสิทธิ์จากเว็บหรือช่องทาง feed/API ที่เขาอนุญาตก่อน ส่วน Vortex Scans และ Kakao Page ยังไม่มี API/RSS ที่ยืนยันการใช้งานสำหรับโครงการนี้ จึงคงเป็น manual/disabled

**ขั้นตอนก่อนเปิดตรวจ:** ผูก ID เรื่องกับแหล่งใหม่ทีละเรื่องโดยให้ผู้ใช้ยืนยัน, ตรวจว่าข้อมูลภาษาและตอนสอดคล้องกับแหล่งนั้น, เพิ่ม attribution ที่ UI, ทดสอบ adapter ด้วย fixture และคำขอสดที่อนุญาต, จำกัดอัตรา/จัดการ 429, แล้วจึงเปิด source ใน private JSON อย่างชัดเจน ห้ามตีความว่าเลขตอนจาก MangaDex/MangaUpdates/WEBTOON คือเลขตอนล่าสุดของ Asura หรือเว็บต้นทางอื่นโดยอัตโนมัติ

MangaBaka เป็น **แหล่ง catalog** ไม่ใช่ source สำหรับ release scheduler: ใช้ ID mapping และ title aliases ได้ แต่ `total_chapters` หรือ `last_updated_at` ของ catalog ไม่ยืนยันเลขตอนล่าสุดของเว็บใด การค้นหา “The Regressor and the Blind Saint” ผ่าน API ได้ 2 ระเบียน จึงห้ามจับคู่กับเรื่องเดิมแบบอัตโนมัติ
